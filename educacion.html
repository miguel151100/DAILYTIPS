Preguntas frecuentes

Dudas sobre los ejercicios.

¿Los ejercicios incluyen respuestas?

La idea es vender cuadernillos con respuestas o guía de solución cuando el producto lo indique.

¿Puedo imprimirlos?

Sí, estarán pensados para descargar, imprimir o resolver desde el dispositivo.

¿Son para secundaria o preparatoria?

Habrá recursos para secundaria, preparatoria, exámenes y regularización.

¿Puedo usarlos desde el celular?

Sí, aunque para resolver ejercicios largos se recomienda tablet o computadora.

¿Cómo recibo el archivo?

Cuando agregues el enlace real de compra, Gumroad o tu sistema de entrega enviará el archivo automáticamente.
