Privacidad y datos

Aviso de Privacidad

DailyTips · dailytips.lat · Última actualización: mayo de 2026

1. Responsable del tratamiento de datos

DailyTips, operado bajo el dominio dailytips.lat, es responsable del tratamiento de los datos personales que se recopilan a través de este sitio web y sus servicios relacionados.

Para cualquier consulta relacionada con este aviso puedes contactarnos en:
WhatsApp: +52 55 6986 2844

2. Datos personales que recopilamos

Al realizar una compra o interactuar con nuestro sitio, podemos recopilar los siguientes datos:

  • Correo electrónico: para entrega de productos digitales, envío del código de acceso y soporte post-compra.
  • Nombre: para personalizar la comunicación y los comprobantes de compra.
  • Datos de pago: gestionados exclusivamente por Mercado Pago. DailyTips no almacena datos de tarjetas, cuentas bancarias ni información financiera sensible.
  • Identificador de compra: número de pago de Mercado Pago para verificar y entregar los productos adquiridos.

3. Finalidad del tratamiento

Usamos tus datos únicamente para:

  • Procesar y confirmar tu compra.
  • Entregarte los productos digitales adquiridos (enlaces de descarga, códigos de acceso).
  • Brindarte soporte si tienes un problema con tu pedido.
  • Enviarte notificaciones relacionadas con tu compra (no enviamos correos de marketing sin consentimiento explícito).

4. Compartición de datos con terceros

DailyTips no vende, renta ni comparte tus datos personales con terceros con fines comerciales. Los únicos servicios que pueden tener acceso a datos necesarios para operar son:

  • Mercado Pago: procesador de pagos. Sus políticas de privacidad aplican para el manejo de datos de pago. Consulta Política de privacidad de Mercado Pago.
  • Supabase: base de datos en la nube utilizada para registrar compras verificadas y generar enlaces de descarga. Los datos se almacenan en servidores con cifrado en tránsito y en reposo.
  • Vercel: plataforma de alojamiento del sitio y las funciones serverless.

5. Tiempo de conservación de datos

Los registros de compra (correo, identificador de pago, producto adquirido) se conservan mientras sean necesarios para soporte al cliente y respaldo de entregas. Si deseas que eliminemos tus datos, escríbenos por WhatsApp o al correo de contacto.

6. Derechos ARCO

Tienes derecho a Acceder, Rectificar, Cancelar u Oponerte al tratamiento de tus datos personales (derechos ARCO). Para ejercerlos contáctanos por WhatsApp con tu nombre, correo con el que compraste y la solicitud específica. Atendemos en un plazo máximo de 20 días hábiles.

7. Uso de cookies y tecnologías de seguimiento

Este sitio no utiliza cookies propias de seguimiento ni herramientas de analítica de terceros actualmente. Si en el futuro se incorporaran, este aviso será actualizado.

8. Seguridad

Implementamos medidas técnicas razonables para proteger tus datos: conexiones HTTPS, acceso restringido a la base de datos y claves de API almacenadas como variables de entorno en servidor. Ningún sistema es 100% seguro, pero tomamos la protección de tus datos con seriedad.

9. Productos digitales — sin envío físico

Todos los productos de DailyTips son entregables digitales. No se envían productos físicos, paquetes ni materiales impresos. La entrega se realiza de forma inmediata tras confirmar el pago, a través de enlace de descarga o código de acceso.

10. Cambios a este aviso

DailyTips puede actualizar este aviso de privacidad en cualquier momento. La versión vigente siempre estará disponible en dailytips.lat/aviso-privacidad.html. Los cambios entran en vigor al publicarse.
